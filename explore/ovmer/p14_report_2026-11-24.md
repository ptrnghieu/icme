## Pipeline defect found in run 1 (all three sets)

| Measure | OV-MERD+ | MER2025-FG | EmoS-MELD-fresh |
|---|---|---|---|
| Descriptions that continue with an invented dialogue turn ("Human:", "User:", …) | 80.6% | 82.0% | 81.9% |
| Empty extractions (all 17 per clip) | 36.2% | 37.1% | 35.7% |
| Empty extraction of the greedy description | 8.6% | 12.7% | 32.8% |
| Greedy extraction written in Chinese (outside the English wheel vocabulary) | 19.5% | 24.0% | 0.5% |

- **Empty extractions:** 85% of them come from descriptions whose first line names an emotion.
- **Not a padding artefact:** the empty rate does not depend on position in the batch or on the amount of padding (0.34–0.39 across padding quartiles).
- **Effect on GREEDY:** it rests on a single extraction, so these failures hit it hardest. The run-1 GREEDY (29–36) is therefore not a valid baseline.
- **Effect on TOPK and MBR:** these aggregate 16 samples and are less affected. Comparisons against them are informative, but they too run on contaminated inputs.

## Amendment 1 (pre-registered 2026-11-24, before any amended output exists)

Pipeline fixes, identical for every decoder. Decision criteria in `p14o_score.py` are unchanged.

1. **Description cut at its first non-empty line.** This is equivalent to generating with a stop at "\n": the first line has the same distribution either way, so the stored samples are reused.
2. **Extraction call as in the official vLLM path** (`AffectGPT-RL/toolkit/utils/qwen.py`, `get_completion_qwen_bacth`):
   - user message only;
   - post-processing with `func_postprocess_qwen`;
   - parsing with `string_to_list` (from `AffectGPT-RL/toolkit/utils/functions.py`);
   - `max_new_tokens` 128.
3. **Chinese labels translated to English** with the official `translate_chi2eng_qwen` prompt.
4. **MER2025-FG completed:** the remaining 284 descriptions are generated with the same settings.

Runner: `explore/ovmer/11_p14_amend1.ipynb`, one Kaggle session.

Report both runs. Run 1 is the pre-registered pipeline. Amendment 1 is the corrected official pipeline, applied without looking at any amended output.
